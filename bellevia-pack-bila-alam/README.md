# BelleVia — باك بلا ألم · صفحة الهبوط

صفحة وحدة، ساكنة (HTML + CSS + JS بلا bundler)، بالدارجة و RTL، مصمّمة لترافيك
الهاتف المغربي وللدفع عند الاستلام.

نفس البنية ديال الصفحات الأخرى ديال BelleVia، ولكن **بنظام ألوان خاص بهاد
المنتوج**: الأخضر ديال الشعار والقنينة، والبرتقالي ديال «Via» ولوحة الثمن، وأرضية
عاجية دافية مأخوذة من الصحرا اللي فالإعلان الرسمي ومن الصالون اللي فقسم `.day`.
كل الألوان تسحبو بالعدّ ديال البيكسلات المشبّعة ديال التصويرة الرسمية ديال الباك.

```
bellevia-pack-bila-alam/
├─ index.html            الصفحة كاملة
├─ style.css             نظام الألوان + كل الأقسام
├─ script.js             السلوك (فورم الطلب، الشريط اللاصق، الأثمنة، التتبّع)
├─ config.js             ← الملف الوحيد اللي خاصك تعمّرو
├─ manifest.webmanifest
├─ assets/
│  ├─ images/            (+ CREDITS.md: منين جات كل صورة)
│  └─ logo/  fonts/  favicon/     مشتركين مع صفحات BelleVia الأخرى
└─ tools/build-assets.mjs   كيصاوب الصور من ملفات العميل
```

`tools/`، `README.md`، `CREDITS.md`، `robots.txt` و `sitemap.xml` ما كيمشيوش مع
النشر — `scripts/copy-landing-pages.mjs` كيحيدهم.

## 1) الفورم فيه 3 حقول، والصفحة ما كتسيفط حتى عنوان

البريف طلب **غير 3 حقول**: الاسم الكامل، رقم الهاتف، والمدينة. هادشي هو اللي
كاين، وما زدنا حتى حقل.

**الصفحة ما كتجمعش العنوان، وما كتسيفطوش.** ماشي عنوان حقيقي، ماشي جملة بديلة،
ماشي علامة. الحقل `address` أصلاً ما كاينش فالـ payload اللي كيخرج من
`payload()` ف `script.js`.

### كيفاش كيخدم هادشي فالـ API

`functions/api/orders.ts` كيقبل طلب الكاطالوگ بلا `address`:

* فـ `catalogSchema` وحدو، `address` ولا **اختياري**
  (`z.string().trim().min(3).max(200).optional()`). `legacySchema` بقا كيورّتو
  مطلوب من `customerFields` — الطريق القديم ديال Nakhwa ما تبدل فيه والو.
* نص خاوي (`""`) باقي كيطيح ف `min(3)` بحال قبل، فصفحة اللي كتسيفط عنوان خاوي
  بالغلط كتّردّ بالضبط كيما كانت كتّردّ.

### الـ guard ف `persist()` — علاش كاين

`Customer` كيتوحّد **بالتيليفون على كل الصفحات** ديال المتجر. فلو سيفطنا شي
جملة بديلة، زبون عندو عنوان حقيقي مسجّل من صفحة أخرى (القمل، الوزن، الراحة،
المفاصل) كيتمسح ليه العنوان ديالو ملي يشري هاد الباك — وما كاين **حتى endpoint**
فالداشبورد كيقدر يرجعو: `admin/customers/[id].ts` غير `GET`، و PATCH ديال
الطلبية كتقبل غير `{status, note}`.

علاش هاكا، `persist()` كيميّز بين تلاتة حالات:

| الطلب | زبون قديم | زبون جديد |
|---|---|---|
| فيه عنوان | كيتكتب (كيما قبل بالضبط) | كيتخزن |
| بلا عنوان | **العنوان القديم كيبقى كيما هو** | كيتخزن `""` |

`""` ماشي جملة بديلة: هو فارغ، و `shared/spaceseller-mapping.js` كيحيد الحقل
كامل ملي يكون فارغ (`if (address) body.address = address`) — فما كاين حتى طرد
كيتعنون بجملة. وأول طلبية جايّة من بعد وفيها عنوان حقيقي كتعمّرو عادي.

هادشي كامل بلا migration وبلا تبديل ديال `prisma/schema.prisma`:
`Customer.address` باقي `NOT NULL`.

⚠️ **العنوان كياخدوه الفريق فمكالمة التأكيد، وهادشي عملية ديال الفريق ماشي
حاجة الصفحة كتسجلها.** الطلبيات ديال هاد الصفحة كتّعرف من عمود «المصدر»
(`source = bellevia-pack-bila-alam`) اللي كيبان فالداشبورد.

الـ regression test ديال هادشي كامل ف `tests/order-persist.pg.test.mjs`.

## 2) قبل الإطلاق — عمّر `config.js`

| الحقل | دابا | خاصك |
|---|---|---|
| `price` | `329` | خاصو يطابق ثمن المنتج فالكاطالوگ. |
| `oldPrice` | `450` | هو الرقم المشطوب اللي كتب عليه الإعلان الرسمي. |
| `productSlug` | `bellevia-pack-bila-alam` | خاصو يطابق slug ديال المنتج فالكاطالوگ. |
| `delivery` | `التوصيل بالمجان` | |
| `deliveryTime` | `من 24 حتى 72 ساعة` | |
| `whatsapp` / `phone` | خاويين | زيدهم وغادي يبانو فالفوتر. |

ما كاينش `addressPlaceholder` ولا أي إعداد ديال العنوان — شوف §1.

**⚠️ 329 درهم خاصها تكون هي نفسها فقاعدة البيانات (32900 سنتيم).** الصفحة كتبين
اللي كاين فـ `config.js`، والفاتورة كتخرج باللي كاين عند الـ API. إلا اختالفو،
الزبون كيشوف ثمن وكيتخلّص ثمن آخر.

إلا مسحتي `price`، كل بلاصة فيها الثمن كترجع تبين `[PRICE]` بخلفية مخططة — علامة
مقصودة باش ما تطلقش إعلان بصفحة بلا ثمن.

## 3) الطلبات — شنو خاص فالباك-إند

الفورم كيسيفط `POST` لـ `/api/orders`:

```json
{ "productSlug": "bellevia-pack-bila-alam", "customerName": "…", "phone": "06…",
  "city": "…", "quantity": 1,
  "source": "bellevia-pack-bila-alam", "sessionId": "…",
  "eventId": "…", "purchaseEventId": "…" }
```

ما كاينش `address` فهاد الـ payload — شوف §1.

باش يخدم، **خاص يكون كاين منتج فالكاطالوگ بهاد الـ slug بالضبط** وبثمن
`32900` سنتيم، وإلا الـ API كيرجع `product_unavailable` والصفحة كتبين للزبون:
«المنتوج ماشي متوفر دابا».

الصفحة **عمرها ما كتسيفط ثمن**. السيرفر هو اللي كيحسب (ثمن الوحدة × الكمية)،
وهادشي مقصود: بلاصة الثمن ماشي فالمتصفح. ما كاينش سطر ديال هاد المنتج ف
`PACK_PRICING`، فالجوج متفقين.

الصفحة تزادت ف `shared/landing-pages.js`، فهي كتتنسخ ل `dist/` مع الباقي وكتبان
فالداشبورد مربوطة بالمنتوج.

## 5) الادعاءات — شنو كتقول الصفحة بصوتها وشنو كتنقلو

هاد الصفحة كتبيع منتوج صحة. القاعدة اللي متبّعة، وهي نفس القاعدة ديال صفحة
Anti-Joint Pain:

**النص ديال الصفحة بصوتها هي عمرو ما كيعاود ادعاء كاين غير داخل شي تصويرة.**

- **بصوت الصفحة:** غير الراحة، الحركة، النهار اليومي، وشنو كاين فالباك. الهيرو
  كيقول «راحة، مرونة، حركة أفضل» — وهي جملة العلامة براسها، وماشي وعد طبي.
  قسم `.day` كيوصف المشكل، وكيقول بالواضح: «باك بلا ألم ماشي حبة سحرية. هو
  روتين يومي».
- **منقول ومنسوب:** جملة العلبة ديال الكبسولات، والأربع سطور بالفرنسية اللي
  مطبوعين على الأنبوب — الجوج تحت `مكتوب على العلبة`. النص بالفرنسية بقا
  بالفرنسية عن قصد: نقلو للعربية كيولّي ادعاء الزبون ما يقدرش يقارنو مع
  الأنبوب اللي فيدو.
- **الفوائد الستة** منقولين حرف بحرف من ورقة الفوائد الرسمية، وتحتهم `.disclose`
  كيقول بوضوح: هادو كلام BelleVia، والكبسولات **مكمل غذائي** والكريم
  **للاستعمال الخارجي** — ماشي دواء وما كيعوضوش استشارة الطبيب.
- **قسم `#campagne`** فيه الإعلان الرسمي وورقة الفوائد **كاملين**، بلا قصّ وبلا
  تعديل ديال أي نص مطبوع داخلهم. العنوان ديالو كيسمّيهم إعلان، والـ `.sec__sub`
  كيقول «النصوص اللي داخلهم هي نصوص ترويجية ديال BelleVia».
- **التحذيرات** منقولين كاملين من ورقة العميل، وعندهم قسم ديالهم بلون خاص —
  ماشي سطر صغير فالفوتر. فصفحة كتبيع مكمل غذائي، التحذير هو سبب ثقة.

**ما كاينش:** آراء زبناء، تقييمات، عدد ديال الزبناء، شهادات ديال أطباء، نتائج
مخبرية، ولا صور «قبل/بعد». ما تزيد حتى وحدة منهم بلا ما تكون حقيقية وموثّقة.

## 6) الوصولية والأداء

- `dir="rtl"` + `lang="ar"`، عنوان `h1` واحد، وترتيب صحيح ديال `h2`/`h3`.
- كل نص/خلفية فالصفحة فوق `4.5:1` (تحسبات كاملة فوق كل توكن ف `style.css`).
- Latin داخل جملة عربية كيتلف بـ `<bdi>` ماشي بـ `.ltr` — `.ltr` عندها
  `display:inline-block` وكتقطع الـ bidi run وكتخربق ترتيب الحروف اللاتينية.
- `prefers-reduced-motion` كيوقف الماركي وكل transition.
- الصور `webp` بـ `srcset`، الهيرو `fetchpriority="high"` و preload، والباقي
  `loading="lazy"`. الوزن الكامل ديال `assets/images/` ≈ 1.2MB.
