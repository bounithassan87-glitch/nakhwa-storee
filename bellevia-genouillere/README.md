# دعامة الركبة الاحترافية · صفحة الهبوط

صفحة واحدة، ساكنة (HTML + CSS + JS بلا bundler وبلا أي مكتبة)، بالعربية
والدارجة و RTL، مصمَّمة لترافيك الهاتف المغربي وللدفع عند الاستلام.

```
bellevia-genouillere/
├─ index.html            الصفحة كاملة
├─ style.css             نظام الألوان + كل الأقسام
├─ script.js             السلوك (الفورم، الكمية، الأثمنة، الشريط اللاصق، التتبّع)
├─ config.js             ← الملف الوحيد اللي خاصك تعمّرو
├─ manifest.webmanifest
├─ assets/
│  ├─ images/            (+ CREDITS.md: منين جات كل صورة وعلاش)
│  └─ logo/  fonts/  favicon/     مشتركين مع صفحات BelleVia الأخرى
└─ tools/build-assets.mjs   كيصاوب الصور من ملفات المورّد
```

`tools/`، `README.md` و `CREDITS.md` ما كيمشيوش مع النشر —
`scripts/copy-landing-pages.mjs` كيحيدهم.

الرابط: **`/bellevia-genouillere/`**

---

## ⚠️ 1) قبل أي نشر: خاص منتوج فالكاطالوگ

**هاد الصفحة كتسيفط الطلب لـ `/api/orders`، ماشي لواتساب.** والـ API كيقلب على
المنتوج بالـ slug وكيرفضو إيلا ما كانش ACTIVE:

```
slug:   bellevia-genouillere
الثمن:  18000 سنتيم  (= 180 درهم)
الحالة: ACTIVE  +  isActive = true
```

**إيلا ما كانش هاد المنتوج، كل طلب من هاد الصفحة كيرجع `product_unavailable`
والزبون كيشوف «المنتوج ماشي متوفر دابا».** الصفحة ما كتدعيش طلب ما تسجّلش —
ولكن الطلب كيضيع. صاوب المنتوج من الداشبورد قبل ما تنشر.

> هاد الصفحة كانت من قبل كتخدم بواتساب بلا أي صف فالكاطالوگ. التبديل لـ
> `/api/orders` هو اللي خلق هاد الشرط الجديد.

ملاحظة: `bellevia-genouillere` مسجّل ف `shared/landing-pages.js`، و
`shared/whatsapp-templates.js` كيعتبر أي صفحة مسجّلة هناك «كتأكد وقت الطلب» —
يعني ملي يتسجل الطلب كتمشي رسالة تأكيد واتساب أوتوماتيكياً. هادشي دابا ولّا
ليه معنى، حيت بدا كاين طلبات.

## 2) الألوان: أبيض + أخضر غامق + ذهبي

* **الأبيض** هو الصفحة ومنصة المنتوج. الدعامة كحلة ومصوّرة على البيض، وكل سطح
  آخر مختار باش ما يتنافسش معاها. السطح الفاتح الوحيد اللي ماشي أبيض هو
  `--shade` (`#FAF8F3`).
* **الأخضر الغامق** هو لون الشرائط: الهيرو، قسم القيمة، العرض، والفوتر.
* **الذهبي** كيبان **غير** على اللي كيتضغط ولا اللي صحيح: زر الطلب، شعيرة تحت
  عنوان، علامة ✓.

⚠️ **الذهبي فخ**: `#C9A227` على البيض كيعطي غير 2.4:1. لذلك كاينين جوج:
`--gold` هو **حشو وشكل** وعمرو ما يكون نص صغير على أرضية فاتحة، و`--gold-ink`
(`#7A5D0A`) هو نفس اللون مدفوع غامق باش **يولي نص** (6.2:1).

الأقسام كتناوب أبيض ← أخضر غامق ← أبيض وما كاين حتى رابع. هادشي هو البريف
حرفياً: «لا تجعل الصفحة كلها خضراء».

## 3) الفورم — خمس معلومات

الاسم الكامل · رقم الهاتف · المدينة · **العنوان** · **الكمية**

القواعد فـ `script.js` **مطابقة بالضبط** لـ `catalogSchema` ف
`functions/api/orders.ts`:

| الحقل | القاعدة |
|---|---|
| `customerName` | 2–100 حرف |
| `phone` | `^0[5-7]\d{8}$` بعد التطبيع |
| `city` | 2–80 |
| `address` | 3–200 |
| `quantity` | عدد صحيح 1–10 (الفورم كيحدّ ف `maxQuantity`) |

التطبيع ديال الهاتف كياخد `+212` و`00212` و`212…` والفراغات والشرطات والأقواس،
وحتى الأرقام العربية-الهندية (`٠١٢…`) — وكيخرج `06XXXXXXXX`.

**علاش نفس القواعد بالضبط:** لو كنا أشد من السيرفر كنرفضو طلبات كان غادي
يقبلها؛ ولو كنا أرخى كنصيفطو الزبون دورة كاملة باش يتقال ليه لا.

### العنوان — هنا كيتجمع، وهادشي مقصود

باقي صفحات BelleVia (بحال `bellevia-pack-bila-alam`) **ما كتسيفطش** حقل
`address` أصلاً، حيت `Customer` كيتوحّد بالتيليفون على كل الصفحات، فجملة بديلة
كتمسح العنوان الحقيقي ديال زبون مسجّل من صفحة أخرى.

هنا العكس: كنجمعو **عنوان حقيقي**، وهادشي بالضبط هو اللي السيسطيم بغا. الـ
`catalogSchema` كيقبل `address` اختياري ولكن نص خاوي باقي كيطيح ف `min(3)`،
فالفورم كيفرضو.

### المدينة — حقل كتابة مع `<datalist>`، ماشي `<select>`

القائمة ف `config.js` اقتراحات، **ماشي قائمة مغلقة**. المغرب فيه مئات البلدات
الصغار، وقائمة مغلقة معناها زبون من بلاد ما مذكوراش ما يقدرش يطلب أصلاً.

### الصفحة عمرها ما كتسيفط ثمن

السيرفر هو اللي كيحسب (ثمن الوحدة × الكمية) من الكاطالوگ. المجموع اللي كيبان
فالفورم هو نفس الحساب، ما دام ما كاينش سطر ديال هاد المنتوج ف `PACK_PRICING`.

## 4) قبل الإطلاق — `config.js`

| الحقل | دابا | ملاحظة |
|---|---|---|
| `price` | `180` | **خاصو يطابق 18000 سنتيم فالكاطالوگ.** |
| `oldPrice` | `299` | مرجع بصري وحدو — ما كيدخلش لا فالخلاص ولا فـ JSON-LD. |
| `delivery` | `التوصيل مجاني` | فارغ = كل ذكر ليه كيتحيد. |
| `deliveryArea` | `لجميع المدن المغربية` | |
| `cashOnDelivery` | `true` | `false` كيحيد كل ذكر للدفع عند الاستلام. |
| `maxQuantity` | `5` | الـ API كيرفض أكثر من 10. |
| `cities` | 67 مدينة | اقتراحات، ماشي قائمة مغلقة. |

إيلا مسحتي `price`، كل بلاصة فيها الثمن كتختافى بوحدها — بلا مربع خاوي وبلا
سعر مخترع. حتى زر «اطلبها الآن بـ …» كيرجع «اطلبها الآن».

## 5) شنو ما كاينش فالصفحة — وعلاش

الصورة المرجعية اللي جات من العميل فيها تلت حوايج ما شدناهمش:

1. **تلاتة ديال آراء الزبناء** بأسماء ومدن ونجوم (أحمد — الدار البيضاء، سعيد —
   مراكش، فاطمة — فاس). **حتى وحدة ما تسيفطات كمراجعة حقيقية**، واختراع أسماء
   وتقييمات هو الحاجة الوحيدة اللي كتحوّل صفحة بحال هادي لصفحة ما خاص حتى حد
   يثق فيها. بلاصتهم دابا قسم «شنو كيهمك قبل ما تطلب؟».
2. **ادعاءات طبية**: «تخفيف الألم والضغط»، «تحمي الركبة من الإصابات»، «تساعد
   على تقليل الألم والتورم». البريف ديالك كيمنعهم صراحة، والترافيك جاي من
   إعلانات Meta.
3. **«ضمان الرضا أو استرجاع الأموال 100%»** و«ضمان الاستبدال والاسترجاع»
   و«خدمة ما بعد البيع متوفرة دائماً» — سياسات ما تأكداتش من حتى مصدر.

الشي الوحيد ديال الاستعجال اللي كاين هو «الكمية المتوفرة حسب المخزون» — جملة
صحيحة وما فيهاش رقم مخترع.

## 6) SEO

`title` / `meta description` / `canonical` / `robots: index, follow` · **`<h1>`
واحد** · `header`/`main`/`section`/`article`/`footer` · Open Graph كامل +
Twitter Card · `alt` وصفي ومختلف لكل صورة.

**JSON-LD**: `Product` + `BreadcrumbList`. فيه `offers` بـ `price: "180"` و
`priceCurrency: "MAD"` و`url` — هادو أرقام مؤكدة دابا حيت كاين منتوج وكاين
فورم كيبيع. **وما فيهش** `availability` (ما عندنا حتى رقم مخزون) ولا `sku` ولا
`aggregateRating` ولا `review`.

العناوين المطلقة كتجي من بديل `__ORIGIN__` اللي كيختمو
`scripts/copy-landing-pages.mjs` عند النشر.

**robots و sitemap**: ما كاينش زوج داخل هاد المجلد وهادشي صحيح —
`copy-landing-pages.mjs` كيحيد أي زوج داخل مجلد صفحة، والجذر كيخدم زوجو الخاص
اللي كيتولّد ف `scripts/set-site-url.mjs` من `LANDING_PAGES`.

## 7) الأداء

صفر مكتبات · الجافاسكريبت كلو `defer` · صورة الهيرو هي LCP (`preload` +
`fetchpriority="high"`، وماشي `lazy`) وكل صورة أخرى `lazy` · `width` و`height`
مصرّح بهما على **كل** صورة و`aspect-ratio` فـ CSS → صفر إزاحة تخطيط · كل
الصور `WebP` عدا `og-cover.jpg` (بعض نسخ واتساب بالمغرب باقة كترفض معاينة
WebP) · لا فيديو ولا حركة تلقائية، والانتقالات كلها كتوقف تحت
`prefers-reduced-motion`.

## 8) التتبّع

`/nk-track.js` المشترك نفسو. الصفحة كتسيفط `ViewContent` عند التحميل،
`InitiateCheckout` عند محاولة صالحة، و`Lead` + `Purchase` **غير ملي السيرفر
يأكد الطلب** — والقيمة هي اللي رجعها الـ API (`total / 100`)، ماشي رقم ثابت.

## 9) الصور

```bash
node bellevia-genouillere/tools/build-assets.mjs
```

**قبل ما تلمس أي صورة اقرا `assets/images/CREDITS.md`**: فيه منين جات كل صورة،
صندوق القصّ، و — الأهم — شنو اللي ما كيتبناش أبداً وعلاش.
