# BelleVia Anti-Joint Pain — صفحة الهبوط

صفحة وحدة، ساكنة (HTML + CSS + JS بلا bundler)، بالدارجة و RTL، مصمّمة لترافيك
الهاتف المغربي وللدفع عند الاستلام.

نفس البنية ديال `../bellevia-weight-gain/`، ونفس نظام التصميم — الملف
`style.css` كيبدا بالنظام المشترك ديال العلامة (أقسام 00–25) وكيسالي بقسم 26
اللي فيه غير اللي خاص بهاد الصفحة.

```
bellevia-anti-joint-pain/
├─ index.html            الصفحة كاملة
├─ style.css             نظام BelleVia + قسم 26 الخاص بهاد الصفحة
├─ script.js             السلوك (فورم الطلب، الشريط اللاصق، الگاليري…)
├─ config.js             ← الملف الوحيد اللي خاصك تعمّرو
├─ manifest.webmanifest
├─ assets/
│  ├─ images/            (+ CREDITS.md: منين جات كل صورة)
│  ├─ logo/  fonts/  favicon/     مشتركين مع صفحة Weight Gain
└─ tools/build-assets.mjs   كيصاوب الصور من ملفات العميل
```

`tools/`، `README.md` و `CREDITS.md` ما كيمشيوش مع النشر — `scripts/copy-landing-pages.mjs`
كيحيدهم.

## 1) قبل الإطلاق — عمّر `config.js`

القاعدة العامة: **أي معلومة ما عمّرتيهاش، الصفحة كتخبّيها ولا كتبيّنها بوضوح.
عمرها ما كتخترع شي حاجة بلاصتك.**

| الحقل | دابا | خاصك |
|---|---|---|
| `price` | `199` | خاصو يطابق ثمن المنتج فالكاطالوگ — الصفحة كتبين هاد الرقم، والـ API هو اللي كيخلّص. |
| `packs` | `[]` | زيدهم إلا بغيتي عروض متدرجة (شوف تحت). |
| `orderApiEndpoint` | `/api/orders` | خليه هكا إلا الصفحة مستضافة مع الـ API. |
| `productSlug` | `bellevia-anti-joint-pain` | خاصو يطابق slug ديال المنتج فالكاطالوگ. |
| `whatsapp` / `social` | خاويين | زيدهم وغادي يبانو فالفوتر. |
| `delivery` | `توصيل داخل المغرب` | |
| `testimonials` | `[]` | خليها خاوية حتى تكون عندك آراء حقيقية. |

إلا مسحتي `price`، بطاقة العرض كترجع تبين `[PRICE]` بخلفية مخططة — علامة مقصودة
باش ما تطلقش إعلان بصفحة بلا ثمن.

**⚠️ 199 درهم خاصها تكون هي نفسها فقاعدة البيانات.** الصفحة كتبين اللي كاين فـ
`config.js`، والفاتورة كتخرج باللي كاين عند الـ API. إلا اختالفو، الزبون كيشوف
ثمن وكيتخلّص ثمن آخر.

## 2) الطلبات — شنو خاص فالباك-إند

الفورم كيسيفط `POST` لـ `/api/orders`:

```json
{ "productSlug": "bellevia-anti-joint-pain", "customerName": "…", "phone": "06…",
  "city": "…", "address": "…", "quantity": 1, "source": "bellevia-anti-joint-pain" }
```

باش يخدم، **خاص يكون كاين منتج فالكاطالوگ بهاد الـ slug بالضبط**، وإلا الـ API
كيرجع `product_unavailable` والصفحة كتبين للزبون: «المنتج ماشي متوفر دابا».

إلا `orderApiEndpoint` بقا خاوي، الفورم كيدخل ل**وضع التجربة**: كيبان تنبيه فوق
الفورم، وأي إرسال كيتردّ برسالة واضحة. **عمرو ما كيبين نجاح كذّاب** — نجاح
مزيّف كيسوى طلبية حقيقية ضايعة.

### العروض (packs) والـ API

الـ API عمرو ما كيقبل ثمن جاي من الصفحة — كيحسب المجموع عندو هو (وهادشي مقصود:
بلاصة الثمن ماشي فالمتصفح). بلا إعداد، كيحسب **ثمن الوحدة × الكمية**.

إلا بغيتي عروض متدرجة، خاص يتزاد سطر فجدول `PACK_PRICING` فـ
`shared/catalog.js`، **بالسنتيم**:

```js
export const PACK_PRICING = {
  "bellevia-weight-gain": { 1: 19900, 2: 34900, 3: 44900 },
  "bellevia-anti-joint-pain": { 1: /* … */, 2: /* … */, 3: /* … */ },
};
```

جوج حوايج خاصك تعرفهم:

1. **الجدول هو الحقيقة، ماشي `config.js`.** الأرقام اللي فالصفحة كتبان غير
   للزبون؛ اللي كيتخلّص هو اللي فالجدول. خاصهم يتطابقو.
2. **ملي يتزاد سطر، المنتج كيتباع غير فهاد الكميات.** أي كمية أخرى كتّرفض بـ
   `pack_quantity_unavailable`. فإلا زدتي `{1,2,3}`، نقّص `max` ديال
   `#quantity` فـ `index.html` من 10 لـ 3، وإلا الزبون يقدر يختار 4 وتتردّ عليه
   الطلبية.

ما دام ما زدتي حتى سطر، خلي `packs: []` فـ `config.js` — الصفحة كتبين stepper
عادي، والـ API كيخلّص بثمن الوحدة، والجوج متفقين.

## 4) الادعاءات — شنو كتقول الصفحة وشنو ما كتقولاش

هاد الصفحة كتبيع منتج صحة. كل جملة فيها مربوطة بشي حاجة يمكن تتحقق منها:

- المكونات والملّيگرامات جايين من ورقة المنتج المتوصل بيها، ومكتوبين كنص حي.
- الوصف ديال المنتج مقتبس **حرفياً** من الملصق، والملصق نفسو مبيّن حداه كصورة.
- الجرعة، المحتوى (30 كبسولة) والتحذيرات كلهم من العبوة.
- الجملة `هذا المنتج مكمل غذائي وليس دواءً…` كاينة فقسم السلامة، فالـ FAQ وفالفوتر.

**ما كايناش**، ولا خاصها تتزاد: نتائج مضمونة، وعود بتخفيف الألم، علاج ولا وقاية
من شي مرض، آراء ولا تنقيط مخترعين، أعداد زبناء، شهادات، دراسات سريرية، ولا
تصاور قبل/بعد. الـ JSON-LD حتى هو ما فيه لا `aggregateRating` ولا `review` —
البيانات المنظمة هي البلاصة اللي فيها رقم مخترع كيتعاود من طرف محرك البحث بحالا
تحقق منو.

## 5) ترتيب الأقسام — علاش هو هكا

الصفحة مبنية على رحلة الشراء، ماشي على لائحة أقسام:

```
1  الهيرو         ← شنو هو، شنو فيه، شحال، وآش ندير دابا
2  الطلب          ← الفورم مباشرة تحت الهيرو
3  المشكل         ← تعرّف على راسك (بلا تشخيص)
4  التركيبة       ← علاش هاد العلبة بالضبط + CTA
5  مناسب لـ       ← «واش مناسب ليا؟»
6  شنو غادي يوصلك ← القيمة + الثمن + CTA
7  الاستعمال      ← ساهل، بلا تحضير
8  الشفافية       ← تفاصيل المنتج + التحذيرات
9  الحملة         ← التصاور الإعلانية ديال العلامة
10 الأسئلة        ← الاعتراضات بالترتيب + CTA
12 CTA الأخير
```

**⚠️ الثلاثة ديال القواعد اللي تحت مقيّسين، ماشي مخمّنين. ما تقلبهمش.**

**⚠️ الفورم خاصو يبقى فالمرتبة 2.** فالنسخة الأولى كان فالمرتبة 9 من 12 —
واللي جاي من إعلان فالفيسبوك ما غاديش يقلب عليه. الحجة كاملة باقية تحتيه لللي
محتاجها، وكل قسم كيسالي حجة كيسالي بنفس الزر.

**والهيرو خاصو يبقى: عنوان ← تصويرة ← ثمن ← زر.** التصويرة كانت أول حاجة، ومقيّس
على 390×844: العنوان كان كيبدا على بعد **538px** والزر على **872px** — يعني أول
شاشة كانت غير بوطاي بلا حتى كلمة وبلا ثمن. دابا: العنوان فـ 79، الزر فـ 761،
وكلشي بائن قبل ما يسكرولي. مقيّس على 360×640، 375×667، 390×844، 414×896
و430×932 — الزر كامل فوق الطية فكلهم. إلا زدتي شي حاجة فالهيرو، عاود قيس.

**⚠️ ما تعاودش نفس تصويرة البوطاي فكل قسم.** كانت خمس مرات فالصفحة (هيرو،
بطاقة العرض، الگاليري، ورقة المواصفات، القسم الأخير) — تلاتة منهم غير تكرار.
حيدت جوج، وربحت ~1100px ديال السكرول. اللي بقاو: الهيرو (كبيرة)، حدا الثمن
(صغيرة)، والقسم الأخير.

**⚠️ ما تستعملش تصاور ديال مفصل بضوء أحمر ولا X-ray.** تلات ملفات من ملف
العميل ما كيتبناوش لهاد السبب — شوف التعليق فـ `tools/build-assets.mjs`. هادي
تصاور ديال عرض ديال مرض، وكتخلي مكمل غذائي يبان بحال دواء.

**⚠️ التذكيرات ديال COD خاصهم يبقاو فوق الزر فالهيرو.** «الدفع عند الاستلام»
و«التوصيل مجاني» كانو تحتيه، ومقيّس: كانو طايحين تحت الطية ف 360×640 و390×844
و414×896 — يعني أهم جوج إشارات ثقة ما كانوش كيبانو فأول شاشة.

**⚠️ `[data-offer-mini]` ما خاصوش يبدا بـ`hidden`.** ملي كان مخبّي وscript.js
كيبيّنو، الزر كان كيتزحزح من بعد أول رسم — CLS مقيّس **0.095**. دابا **0.003**.

**⚠️ `setBusy()` ما خاصهاش تكتب `innerHTML` ديال الزر.** كانت كتقتل
`#submitTotal`، والمجموع كان كيتجمّد: واحد فشل عندو الإرسال (أنترنت ضعيف)،
بدّل الكمية لـ3، وكيشوف «199 درهم» وكيتخلّص 597. دابا كتبدّل غير جوج `span`.

### الثمن والكمية

الفورم كيبين المجموع وكيعاودو داخل الزر (`#submitTotal`)، وكيتبدل ملي كتبدل
الكمية. بلا packs، الحساب هو **ثمن الوحدة × الكمية** — وهو بالضبط اللي كيحسب
الـ API لمنتج بلا سطر فـ `PACK_PRICING`، فالرقم اللي فالزر هو الرقم ديال
الفاتورة. إلا زدتي packs، الفرع الأول ديال `orderTotal()` كياخد البلاصة وكيبقاو
متفقين.

## 6) التحقق

الصفحة تشيّكات على 390 / 834 / 1440 بـ Playwright: بلا سكرول أفقي، بلا أخطاء
كونسول، بلا صور مكسّرة، الأيقونات كلها كتحل، وكتخدم بلا JavaScript. حاجتين
تعاودهم إلا بدّلتي النص العربي:

- **ما تلفّش أسماء لاتينية بـ `.ltr` وسط جملة عربية.** الكلاس هو
  `inline-block`، وكيقطع الـ bidi run فكل حدود span، فالترتيب كيتخربق.
  استعملها غير للأرقام والأثمنة الواقفة بوحدها.
- **حط مسافة من الجهتين ديال «و» ملي تكون بين أسماء لاتينية.** `…وChondroitin`
  ملي كيتقلب لـ RTL كيحط الواو على ليسر ديال الاسم اللي قبلو، وكيتقرا
  `Chondroitinو`.
- **تفادى علامة الاستفهام مورا كلمة لاتينية فآخر عنوان** — كتمشي لأقصى ليسر
  ديال السطر وكتبان بحال إلا كتخص الجملة اللي مورا.
