# Bellevia Weight Gain — landing page

صفحة هبوط لمنتج **Bellevia Weight Gain** (مكمل غذائي، 30 كبسولة)، موجهة للسوق
المغربي وبالدارجة، ومصمّمة أساساً للترافيك ديال Facebook / Instagram Ads.

HTML5 + CSS3 + Vanilla JS. بلا framework، بلا npm، بلا build، بلا compilation.
كل المسارات نسبية بـ `./`، فالصفحة كتخدم كاملة ملي تحل `index.html` ديركت من
`file://` بحال ملي تكون مستضافة. الخطوط والصور كلها محلية — ما كاين حتى طلب
لسيرفر خارجي، وكتخدم حتى بلا أنترنت.

```
bellevia-weight-gain/
├─ index.html            الصفحة كاملة
├─ style.css             التصميم (mobile-first · RTL)
├─ script.js             المكونات: الفورم، الشريط اللاصق، الـ lightbox، الأثمنة
├─ config.js             ← الملف الوحيد اللي خاصك تعمّرو
├─ manifest.webmanifest  · robots.txt · sitemap.xml
├─ assets/
│  ├─ logo/     الشعار      · images/  الصور · شوف images/CREDITS.md
│  ├─ fonts/    Tajawal 400/700/800 (woff2، عربي + لاتيني)
│  ├─ favicon/  الأيقونات   · videos/  خاوي — ما كاين حتى فيديو
└─ tools/       سكريبتات توليد الصور من ملفات العلامة (ماشي ضرورية للتشغيل)
```

## 1 · التشغيل

**حل `index.html` ديركت** ف Chrome. صافي.

إلا بغيتي سيرفر محلي (باش تجرّب الـ manifest ولا preload ديال الخطوط، اللي
كيتفعّلو غير على http):

```bash
npx -y serve bellevia-weight-gain -l 5178
```

**للنشر:** طلّع محتوى `bellevia-weight-gain/` كما هو ل Cloudflare Pages ولا
Netlify ولا Vercel ولا أي استضافة عادية. ما كاين حتى build command.

## 2 · التعمير قبل الإطلاق

كلشي كيتعمّر ف **`config.js`** وحدو. ما كاينة حتى قيمة مخترعة فيه: كل شي خاوي
بمعنى placeholder.

### القاعدة العامة

| الحالة | شنو كتدير الصفحة |
|---|---|
| الحقل خاوي | كتخبّي الجزء المعني — ما كتخترعش قيمة بلاصتك |
| `price` خاوي | بطاقة العرض كتبيّن **`[PRICE]`** بخلفية مخططة، باش ما يمكنش تنسى. الأثمنة المختصرة (الهيرو، آخر الصفحة، الشريط اللاصق) ما كيبانوش أصلاً، فالصفحة تبقى شكلها كامل |
| `orderApiEndpoint` خاوي | الفورم كيدخل ل**وضع التجربة**: تنبيه فوق الفورم، وأي إرسال كيتردّ برسالة واضحة بللي الطلب **ما تسجّلش**. عمرو ما كيبين نجاح كذّاب |
| `testimonials` خاوية | قسم الآراء ما كيبانش أصلاً |
| `whatsapp` / `phone` / `social` خاوين | قسم «تواصل معانا» فالفوتر كيتخبّى |
| `delivery` خاوي | كيتحيد ذكر التوصيل من بطاقة العرض ومن شريط الثقة فالهيرو |
| `cashOnDelivery: false` | كيتحيد **كل** ذكر ديال الدفع عند الاستلام: شريط الثقة فالهيرو، بطاقة العرض، جدول المقارنة، الإحصائيات، سؤال FAQ، والـ CTA الأخير |

### أ · ربط الطلبات بالـ API ديال المشروع

المشروع عندو ديجا endpoint كيقبل هاد المنتج بلا ما تبدّل فيه والو
([functions/api/orders.ts](../functions/api/orders.ts) — CORS مفتوح):

```js
orderApiEndpoint: 'https://<الدومين-ديالك>/api/orders',
```

الفورم كيسيفط POST بصيغة JSON:

```json
{ "productSlug": "bellevia-weight-gain", "customerName": "…", "phone": "0612345678",
  "city": "…", "address": "…", "quantity": 2, "source": "bellevia-weight-gain" }
```

وكيتسنى `{ ok: true, orderNumber }`. **النجاح كيتحدد بجواب السيرفر وحدو** —
الصفحة عمرها ما كتعلن تسجيل الطلب من راسها.

باش يخدم، خاص يكون كاين منتج فالكاطالوگ بنفس الـ `productSlug`، وإلا كيرجع
`product_unavailable` (ومترجم للمستخدم بالدارجة).

الرقم كيتنضّف قبل الإرسال: `+212 6…` و`00212 6…` و`212 6…` كلهم كيوليو `06…`.

### ب · الأثمنة

```js
price: '199',        // → «199 درهم»
oldPrice: '299',     // خاوي = ما كاين حتى ثمن مشطوب
offer: 'توصيل مجاني',// خاوي = ما كاينة حتى شارة عرض
currency: 'درهم',    // الكلمة اللي كتبان للزبون
currencyCode: 'MAD', // كود ISO — كيمشي غير لـ schema.org
```

إلا كتبتي الوحدة راسك (`'199 DH'`)، كتبان كيفما كتبتيها.

الـ **JSON-LD** ديال `Offer` كيتزاد أوتوماتيكياً غير ملي يكون `price` معمّر و
`currencyCode` صالح (3 حروف). Offer ناقص ولا غالط خير منو ما يكونش، فإلا ما
تحققاتش هاد الشروط كيتحيد نهائياً.

### ب-2 · العروض والـ API ⚠

`config.js` فيه `packs`، والصفحة كتبيّن مُنتقي العروض وكتحسب التوفير وحدها:

```js
packs: [
  { qty: 1, label: '1 علبة' },              // كياخد الثمن من `price`
  { qty: 2, label: '2 علب', price: '349' }, // وفري 49  (2×199 − 349)
  { qty: 3, label: '3 علب', price: '449', badge: 'الأكثر توفيراً' }, // وفري 148
]
```

**الثمن اللي كيتسجل كيحسبو السيرفر، ماشي الصفحة.** الأثمنة ديال العروض
مكتوبة مرتين — وحدة للعرض ووحدة للحساب — وخاصهم يبقاو متطابقين:

| فين | الملف | كيخدم لـ |
|---|---|---|
| العرض | `bellevia-weight-gain/config.js` → `packs` | شنو كتشوف الزبونة |
| **الحساب** | `shared/catalog.js` → `PACK_PRICING` | **شنو كتخلص فعلاً** |

```js
// shared/catalog.js — بالسنتيم
export const PACK_PRICING = {
  "bellevia-weight-gain": { 1: 19900, 2: 34900, 3: 44900 },
};
```

`functions/api/orders.ts` كياخد المجموع من هاد الجدول، وكيحط `subtotal` و
`discountAmount` باش التخفيض يبان فالطلب. الصفحة عمرها ما كتصيفط ثمن، وحتى
إلا صيفطات واحد كيتجاهل — فحتى واحد ما يقدر يطلب بدرهم.

**كمية ماشي فاللائحة (4، 10…) كتترفض** بـ `invalid_quantity`، حيت ما كاين
حتى ثمن صحيح ليها. المنتجات الأخرى اللي ماشي فـ `PACK_PRICING` باقين على
ثمن الوحدة × الكمية بحال قبل.

> ⚠ **إلا بدّلتي شي ثمن، بدّلو ف الجوج بلايص.** إلا تبدّل غير `config.js`،
> الزبونة غادي تشوف ثمن والسيرفر غادي يسجل ثمن آخر. الاختبار
> `tests/money.test.ts` كيقفل على أرقام `PACK_PRICING`.

⚠ **باقي**: مسار السلة (`lines`) — إلا تباع هاد المنتج من السلة ديال المتجر
الرئيسي، باقي كيتحسب بثمن الوحدة × الكمية. الصفحة هادي ما كتستعملش داك المسار.

### ج · التتبّع (Meta Pixel / GA)

## 3 · الآراء — علاش خاوية

`testimonials: []` وقسم الآراء ما كيبانش. **ما كتبنا حتى رأي من عندنا**: رأي
مكتوب من طرف اللي صاوب الصفحة كيبقى مخترع مهما تصاغ، وحطّانو بحال آراء الزبناء
كيغلط المشتري.

ملي تكون عندك آراء حقيقية:

```js
testimonials: [
  { text: 'النص ديال الرأي', name: 'سعاد، الرباط', verified: true },
]
```

- `verified: true` → علامة عادية («رأي زبون»).
- بلا `verified` → علامة واضحة: «نموذج توضيحي — ماشي رأي زبون موثّق»، وكيتزاد
  سطر تحت العنوان كيوضح هادشي. **استعملها غير باش تشوف الشكل، ماشي فالإنتاج.**

## 4 · شنو كتقول الصفحة وشنو ما كتقولهاش

هادي ماشي تفاصيل صغيرة — هادي هي اللي كتخلي الصفحة تقدر تدوز فإعلان.

**كل معلومة على المنتج فالصفحة مأخوذة من الملصق**: 14 مكوّن بالنسب ديالهم،
الجرعة (1 إلى 2 كبسولة يومياً بعد كل وجبة مع كوب من الماء)، 30 كبسولة،
والتحذيرات. الملصق الأصلي كيبان كتصويرة حدا النص، باش الزبون يقدر يقارن.

**اللي ما كتقولوش الصفحة**، حتى إلا كان مكتوب فالإعلانات اللي عطات العلامة:

- «100% طبيعي» · «بدون آثار جانبية» · «مضمون»
- «+5000 عميل راضي» · «95% نسبة رضا العملاء» — أرقام ما عندنا باش نأكدوها
- أي وظيفة صحية منسوبة لمكوّن معيّن
- أي نتيجة ولا مدة («فـ30 يوم…»)
- تصاور قبل/بعد

والتحذير ديال العلبة كامل كاين فقسم خاص بيه، بما فيه: «هذا المنتج ليس مخصصاً
لتشخيص أو علاج أو شفاء أو منع أي مرض. هذا ليس دواء.»

حتى **الدفع عند الاستلام والتوصيل** ماشي مكتوبين ثابتين فالـ HTML: بجوج مربوطين
بـ `config.js`، حيت هوما وعود على خدمة. حط `cashOnDelivery: false` وغادي يختافى
كل ذكر ليهم من الصفحة (7 بلايص). و`<meta description>` ما كيوعدش بيهم أصلاً،
حيت كيتقرا قبل ما يخدم أي سكريبت.

شوف [`assets/images/CREDITS.md`](assets/images/CREDITS.md) على قواعد الصور.

## 5 · تفاصيل تقنية

**الجمهور**: الصفحة موجّهة للنساء، وكل الـ copy مكتوب **بصيغة المؤنث**
(«اطلبي الآن»، «كتعاني»، «شوفي المكونات»). إلا بغيتي ترجّعها محايدة، البدال
كلها ف `index.html` وحدو — ما كاين حتى نص جايّ من السكريبت.

**ترتيب الصفحة** مبني على رحلة الشراء، ماشي على عرض المنتج:
هيرو → **الطلب** → المشكل → الحل → المميزات → المكونات → الاستعمال → نمط الحياة
→ علاش Bellevia → الآراء → FAQ → تفاصيل المنتج + التحذيرات → CTA أخير.

**صورة الموديل**: ما عندناش تصويرة فيها موديل ممسكة بالعلبة. الهيرو فالديسكتوب
كيركّب جوج تصاور منفصلين (العلبة + بورتري) بدل ما نخترعو وحدة. ملي تجيك تصويرة
حقيقية، بدّل `.hero__model` بيها ولا حيّد الجوج وخلي `.hero__product` وحدو —
الـ layout ما كيتبدلش. فالموبايل البورتري ديال الهيرو مخبّي أصلاً: تصويرة ثانية
تما كتزيد تحميل قبل الـ LCP وكتهبّط الـ CTA تحت الطية.

الفورم جاي **directement تحت الهيرو**: الزائر الجاي من إعلان ما خاصوش يقلّب
عليه. باقي الصفحة كتشتغل باش تجاوب على الاعتراضات ديال اللي ما طلبش من اللول،
وكل CTA فيها كيرجع لنفس الفورم.

- **Mobile-first.** فالموبايل، العلبة كتجي **قبل** العنوان (`order: -1`) باش
  المنتج يكون على الشاشة ملي تتحل الصفحة — أغلب الترافيك جاي من إعلان بان فيه
  المنتج. الترتيب فالكود بقا العنوان أولاً، فالقراية والـ SEO ما تبدلوش.
- **صفر horizontal scroll** فـ 390 / 834 / 1440.
- **صور responsive**: `srcset` + `sizes` + `width`/`height` على كل صورة (بلا
  layout shift)، WebP، و`loading="lazy"` على كلشي ماعدا الهيرو (اللي عندو
  `fetchpriority="high"` و`preload`).
- **الخطوط محلية** ومقسّمين عربي/لاتيني بـ `unicode-range`، فالجهاز اللي كيقرا
  غير العربية ما كيحمّلش اللاتيني.
- **الأنيميشن** خفيف (fade + slide)، وكيتحيد كامل مع
  `prefers-reduced-motion`.
- **شبكة أمان للأنيميشن**: كل عنصر `.reveal` كيبدا `opacity: 0`، فإلا ما
  خدماش الـ `IntersectionObserver` (تبويبة كتحمّل فالخلفية، prerender…) غادي
  تبقى الصفحة خاوية. كاين timer ديال 3 ثواني: إلا ما بان حتى عنصر، كيتحيد
  التأثير وكيبان كلشي. وزيادة على هادشي، **الهيرو ما فيه حتى `.reveal`** —
  فحتى إلا طاح الجافاسكريبت كامل، الجزء الأول ديال الصفحة كيبان بحالو.
- **بلا جافاسكريبت**: الصفحة كتبان كاملة (قاعدة الإخفاء مربوطة بـ `.js` اللي
  كيزيدها السكريبت). اللي كيوقف: إرسال الفورم، الـ lightbox، وطي الجدول.
  الـ FAQ خدام بـ `<details>` بلا سكريبت.
- **إمكانية الوصول**: `<html dir="rtl" lang="ar">`، هيكل عناوين متسلسل، skip
  link، `aria-label` على كل زر بلا نص، أخطاء الفورم بـ `role="alert"` و
  `aria-invalid`، focus ring واضح، وكل هدف لمس ≥ 44px.
- **SEO**: عنوان ووصف، Open Graph + Twitter card، `Product` JSON-LD،
  `alt` على كل صورة، و`<table>` حقيقي للتركيبة.
